# 08. 비용과 시연의 한계 — 돈이 드는 것, 시연으로는 무리인 것, 표준에서 벗어난 것

> 모든 금액은 **AWS 서울 리전 온디맨드 정가 기준 대략치**(USD, 세금 별도)다. 가격은 바뀔 수 있으므로 `terraform apply` 전에 AWS 요금 계산기로 다시 확인한다.

> 앞에서 말씀드린 "월 $60~100"은 Keycloak, BFF용 web, Redis, 공인 IPv4 요금을 빼고 낮게 잡은 숫자였다. 이 표가 정정된 값이다.

### 줄이는 방법 (효과 큰 순)
| 방법 | 절감 | 대가 |
|---|---|---|
| **안 쓸 땐 `terraform destroy`, 시연 전 `apply` + 시드** | 꺼둔 기간 전부 | 다시 만드는 데 15~25분 (RDS가 가장 느림) |
| ECS 태스크를 ARM64(Graviton)로 | Fargate 약 20% | 이미지를 ARM으로 빌드 (멀티 아키텍처 빌드) |
| worker를 **Fargate Spot**으로 | worker 최대 약 70% | 중단될 수 있음 → SQS 재시도로 흡수 (오히려 좋은 설명 소재) |
| worker를 api에 합치기 (시연 한정) | $12 | ⚠️ 표준에서 후퇴. 비추천 |

### 크레딧으로 충당되나?
- AWS는 **2025년 7월 15일 이후 가입한 신규 계정**에 크레딧 $100을 주고, 온보딩 활동을 마치면 최대 $200까지 늘려준다. Free 플랜은 **가입 6개월 후 또는 크레딧 소진 시** 끝난다.
- 개발 5일 + 면접까지 2~3주를 켜두면 대략 $70~100이다. **크레딧 안에서 해결될 가능성이 높다.** 그래도 **예산 알림이 먼저**다.
- Free 플랜에서는 일부 서비스나 기능이 제한될 수 있다. 막히면 Paid 플랜으로 바꿔도 남은 크레딧은 쓸 수 있는 것으로 안내돼 있다. **가입할 때 Billing 콘솔의 크레딧 화면에서 직접 확인한다.**
- **2025년 7월 15일 이전에 만든 계정**은 예전 프리티어(12개월) 규칙을 따른다. 가입한 지 1년이 지났다면 무료 혜택 없이 정가가 나온다.

### 사용량에 비례하는 비용 — 영상

위 표는 켜두기만 해도 나오는 **고정 비용**이다. 영상은 올리고 볼 때마다 나오는 **변동 비용**이 따로 있다.

| 항목 | 과금 방식 | 시연 규모 추정 |
|---|---|---|
| **MediaConvert** | **출력 영상 분당** 과금. 해상도(SD/HD)와 티어에 따라 단가가 다르다 | 미국 리전 기본 티어 기준 HD 분당 약 $0.015 → 30분 강의를 3가지 화질로 변환하면 **영상 1개당 약 $1 안팎** (서울 단가는 요금표로 확인) |
| S3 저장 | GB·월 | 원본 + 3가지 화질 합쳐 강의 1개당 1~2GB → 월 몇 센트 |
| CloudFront 전송 | GB당 (무료 구간 있음) | 데모 시청 수준이면 무료 구간 안 |

- **시연용 데모 영상은 3~5개, 각 5~10분**으로 짧게 준비한다. 변환 비용이 1~2달러 안에서 끝난다.
- 개발 중에는 `VideoTranscoder`의 **가짜 구현**을 써서 변환 비용이 나오지 않게 한다. 실제 MediaConvert는 배포 환경에서만 부른다.
- AWS Free 플랜에서 MediaConvert 사용이 제한되는지는 **가입 후 콘솔에서 확인**한다. 막히면 Paid 플랜으로 전환하거나 후퇴안(H.264 mp4 원본 재생)을 쓴다.
- 규모가 커지면: 변환 비용 → **ffmpeg 워커 + Fargate Spot**으로 교체(인터페이스 뒤라 구현만 바꾼다), 전송 비용 → 화질 단계와 비트레이트 조정.

## 3. 시연으로는 무리인 것 (돈 또는 시간·환경 때문에)

| 항목 | 업계 표준 | 왜 무리인가 | 이번에 대신 하는 것 |
|---|---|---|---|
| 쿠버네티스(EKS) + Argo CD | 대규모 서비스 표준 | 클러스터만 월 약 $73, 학습 시간 | ECS Fargate (문서에 전환 기준 명시) |
| 고가용성 (Multi-AZ RDS, 서비스당 태스크 2개+) | 운영 필수 | 비용 약 2배 | 단일 구성. Terraform 변수만 바꾸면 되도록 작성 |
| 스테이징 환경 상시 운영 | 표준 | 비용 2배 | `envs/staging` 정의만, 필요할 때만 `apply` |
| NAT Gateway + 프라이빗 서브넷 앱 | 표준 | 월 약 $45 이상 | ⚠️ 퍼블릭 서브넷 + 보안 그룹 (§4) |
| AWS WAF | 표준 | 월 $5 + 규칙당 $1 | 문서로만 |
| 다중 리전 재해 복구 | 대기업 표준 | 비용·복잡도 | RDS 자동 백업 + 특정 시점 복구만 |
| SES 운영 전환(샌드박스 해제) | 운영 필수 | AWS 심사 필요, 보장 안 됨 | 샌드박스 + 인증된 데모 주소 |
| **실제 고객사 SSO** (Okta, Entra ID) | B2B 필수 | 고객사 IdP 환경 필요 | Keycloak 두 번째 렐름을 "고객사 IdP"로 꾸며 시연 |
| **SCIM** 직원 자동 동기화 | 엔터프라이즈 표준 | 고객사 IdP 필요 | 문서로만 |
| **SCORM 패키지 재생**, LTI 1.3, cmi5 | LMS 표준 | 5일 안에 구현 불가 | xAPI 기록 구조로 기반만 마련 |
| 실제 규모 부하 테스트 | 표준 | 비용·시간 | k6로 소규모 측정 (Could) |
| 백업 복구 훈련 | 표준 | 시간 | 문서로만 |

## 4. 돈이 있어도 개인이 할 수 없는 것 (계약·인증 필요)

| 항목 | 이유 | 면접에서 할 말 |
|---|---|---|
| 영상 DRM (Kollus, PallyCon 등) | 유료 계약 | "유료 콘텐츠 보호가 필요하면 DRM 업체 연동을 검토합니다" |
| 휴대폰 본인인증 (PASS 등) | 사업자 계약 | "환급과정에는 본인 확인 요건이 붙는 것으로 압니다" |
| 고용보험 환급과정 HRD-Net 연동 | 승인받은 훈련기관만 가능 | 회사가 이 시장을 노리는지 **역으로 질문** |
| ISMS-P, SOC 2 인증, 모의해킹 | 비용·기간 | 감사 로그, 접근 통제를 인증 요건을 의식해 설계했다고 설명 |
| AWS Shield Advanced | 월 수천 달러 | Shield Standard(무료)로 기본 방어 |

## 5. ⚠️ 업계 표준에서 의도적으로 벗어난 곳 (전체 목록)

| 벗어난 곳 | 표준 | 이유 | 운영이라면 |
|---|---|---|---|
| ECS 태스크를 퍼블릭 서브넷에 둠 | 프라이빗 서브넷 + NAT | NAT가 단일 항목으로 가장 비쌈 | 프라이빗 서브넷 + NAT 또는 VPC 엔드포인트 |
| 서비스당 태스크 1개, RDS 단일 AZ | 2개 이상, Multi-AZ | 비용 | 숫자만 변경 |
| 스테이징 미운영 | 개발/스테이징/운영 | 비용 | `envs/staging` apply |
| WAF 없음 | WAF 관리형 규칙 | 비용 | WAF 추가 |
| Keycloak을 직접 운영 | 관리형 IdP도 흔함 | 비용 0원 + SSO·조직 기능 | 팀 규모에 따라 관리형 전환 검토 |
| PR별 미리보기 환경 없음 | Vercel 등에서 흔함 | ECS로 옮기며 포기 | Chromatic PR 미리보기로 UI만 대체 |
| SES 샌드박스 | 운영 전환 | 심사 필요 | 운영 전환 신청 |
| (후퇴안을 쓸 경우) 원본 mp4 재생 | HLS 적응형 스트리밍 | 일정 부족 | MediaConvert 변환 파이프라인 연결 |

> 이 표가 있다는 것 자체가 면접 포인트다. **"표준을 알고, 제약 때문에 어디를 왜 벗어났고, 운영이라면 어떻게 바꿀지 안다"** 는 걸 보여준다.
