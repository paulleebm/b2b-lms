## 3단계 — 5개 관점 점수

**1. 방향 일관성 — 8/10**
근거: 먹남 셸 · 주 버튼 · 인주 인장 · 남청 강조의 역할이 모든 화면에서 같다. 인장은 수료 행, 수료 완료 화면, 랜딩의 수료자에만 나온다.
감점: 로고의 한자 "學"은 인장 세계와 맞지만 유니코드 글자를 로고로 쓴 임시 처리다. 랜딩 h1이 토큰 밖 크기(40/48px)를 쓴다.

**2. 시각 위계 — 7/10**
근거: 조정 후 관리자 첫 화면에 제목 → 요약 → 경고 → 처리 대상 표가 순서대로 보인다. 학습자는 "다음 할 일"이 맨 위다.
감점: 요약 띠의 "마감 지남"(빨강 숫자)과 바로 아래 위험 알림이 같은 사실을 두 번 강조한다. 하나를 낮출 여지가 있다.

**3. 디테일 — 7/10**
근거: 숫자 오른쪽 정렬 + 고정폭 숫자, 극단값(25자 이름, 40행)에서 말줄임 + title, 고정 열 구분선, 선택 영역·캐럿·스크롤바까지 토큰 색.
감점: 모바일 표는 아직 가로 스크롤이다. 진도 막대 값 칸(w-14)이 "4/6 레슨"처럼 긴 값에서 빠듯하다.

**4. 기능성 — 8/10**
근거: 리마인더 → "보냄" + 스크린리더 안내(live region), 정렬 헤더 `aria-sort`, 차트 대체 표, 모바일 메뉴의 포커스 관리. 58개 스토리 테스트가 실제 브라우저에서 이를 검증한다.
감점: 실제 API와 연결된 관리자·학습자 화면은 아직 없다(Day 3~4). 회사 등록 폼은 컴포넌트 스토리로만 확인했고, 로그인 세션이 필요한 실제 화면은 다시 확인하지 않았다.

**5. 독창성 — 6/10**
근거: 수료 인장(형태, 기울기, 한 번만 찍히는 연출, 표·배지·랜딩까지 이어지는 일관성)이 다른 SaaS와 구별되는 지점이다.
감점: 그 외 구성은 의도적으로 표준이다(업무 도구에서는 감점 사유가 아님).

**판정:** 통과선(7 / 7 / 7 / 8 / 5)을 모두 넘었다. 단, 4번(기능성)은 9번 수정 이후에야 통과했다.
